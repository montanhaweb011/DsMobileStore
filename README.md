# DS Mobile Store

Site estático responsivo em HTML, CSS e JavaScript. Abra `index.html` para visualizar. Nenhuma instalação ou compilação é necessária.

## Arquivos
- `index.html`: conteúdo, contatos, depoimentos e metadados.
- `styles.css`: visual, layout responsivo e animações.
- `script.js`: menu móvel, animações no scroll e progresso da leitura.
- `assets/loja.jpg`: foto real da fachada, incluída no projeto.
- `assets/favicon.svg`: ícone do site.

## Publicar
O projeto pode ser publicado diretamente no GitHub Pages: nas configurações do repositório, em Pages, selecione a publicação por branch, `main`, pasta `/ (root)`. Também funciona em qualquer hospedagem de arquivos estáticos. A publicação e o domínio não são configurados pelo código.

## Conteúdo
Endereço, telefone e depoimentos fornecidos pelo proprietário do projeto. Nota de 5,0 e 107 avaliações reproduzem os dados recebidos; não há sincronização com o Google. Horários completos não foram informados, por isso o site orienta a confirmação por WhatsApp. Preços, prazos e garantias não foram presumidos. Os botões abrem WhatsApp, Instagram, telefone ou Google Maps; não há formulário nem coleta de dados pelo site.

A fotografia foi obtida do link do Google Maps fornecido no pedido. Fontes Manrope e DM Sans carregam do Google Fonts, com fontes locais alternativas. A foto é local e não depende do Google para aparecer. Animações respeitam a preferência de movimento reduzido; conteúdo permanece visível quando JavaScript está desativado.
